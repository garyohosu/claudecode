# 3D Othello - Three.js

Three.jsを使った3Dオセロ（リバーシ）ゲームです。美しい3Dグラフィックスとアニメーションで、古典的なオセロゲームを楽しめます。

## 特徴

- **3Dグラフィックス**: Three.jsを使った美しい3D表現
- **アニメーション**: 駒の配置と裏返しのスムーズなアニメーション
- **インタラクティブ**: マウスでクリックして駒を配置
- **リアルタイムスコア**: 黒と白の駒の数をリアルタイム表示
- **回転カメラ**: ゲームボードを自動的に回転するカメラビュー

## ゲームルール

オセロは2人用のボードゲームです：

1. 8x8のボードで黒と白の駒を使ってプレイ
2. 黒から開始し、交互にターンを進める
3. 相手の駒を自分の駒で挟むことで裏返す
4. 置ける場所がない場合はパス
5. 両者とも置けなくなったらゲーム終了
6. 駒の数が多い方が勝利

## セットアップ

### 必要なもの

- Node.js (v16以上推奨)
- npm

### インストール

```bash
# リポジトリをクローン
git clone <repository-url>
cd claudecode

# 依存関係をインストール
npm install
```

## 使い方

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで http://localhost:5173 を開いてゲームをプレイできます。

### ビルド

```bash
npm run build
```

ビルドされたファイルは `dist/` ディレクトリに出力されます。

### プレビュー

```bash
npm run preview
```

## 操作方法

- **駒の配置**: マウスで配置したいマスをクリック
- **リセット**: 左上の「リセット」ボタンをクリック
- **視点**: カメラは自動的にボードの周りを回転します
